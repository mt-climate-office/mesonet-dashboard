# Legacy Dashboard Fidelity Checklist (web-next)

Inventory of the behaviours of the legacy Dash app (`app/mdb`, origin/main, including commit
`5afb746f` "grey outage boxes end on sensor replacement"), copied from
`web/scripts/fidelity/CHECKLIST.md` (frozen with `web/`). That file audited the React app
(`web/`); this copy adds a **web-next status** column for the W4 cutover gate.

Columns:

- **ID**: stable identifier, by section prefix.
- **Feature / expected behavior**: what the legacy app does, with concrete defaults, option lists, limits, labels, units and colours. Anything not read directly from code is marked *(inferred)*. Items marked **[legacy bug]** describe behaviour that is probably unintended.
- **Legacy ref**: `file:line` relative to `app/mdb/`.
- **Auto**: `H` = automatable by the harness, `P` = partially, `M` = manual.
- **web/ status**: the React app's audit (cutover-gate audit of 2026-10-01; paths relative to `web/src/`). Kept for reference.
- **web-next status**: one of `match`, `intentional divergence` (citing the `web-next/DIVERGENCES.md` section, or its "House style › Data colors" table for colours, cited as "palette <ID>"), `gap (P1|P2|P3)` with a fix, `legacy bug – not ported`, `n/a (satellite deferred)`. Paths are relative to `web-next/` (`src/…`, `partials/…`). "harness:" cites `scripts/fidelity/run.mjs` results (web-next vs web/ on the same API at level 2, 1440 px, light theme; run 2026-10-01, `results.json` / `report.html`; rows ending "(P2)" cite the 2026-10-02 run on the UX-refactor routes). Statuses come from reading the web-next code against legacy and the DIVERGENCES entries, plus the harness and its screenshots; "(code-verified)" marks a runtime behaviour judged from code.

API base is `https://mesonet.climate.umt.edu/api/` (`utils/params.py:23`), written `{API}` below.
